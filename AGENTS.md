# Работа с проектом

Репозиторий игры: https://github.com/AntoninaLamert/troyka (remote `origin`, ветка `main`).

По просьбе владельца после завершения изменений проекта и необходимых проверок фиксируйте их в Git и отправляйте в этот репозиторий. Перед отправкой получайте актуальную удалённую историю и сохраняйте изменения, сделанные на GitHub.

Для HTTPS используется Git Credential Manager и диспетчер учётных данных Windows. Токены и другие секреты нельзя записывать в файлы проекта, адрес remote, коммиты или сообщения.
